# assets folder
___
#### [This folder][link_assets] is for the asset files used by the application.
___

It is divided into 4 folders to organise audio, data, fonts and images.
These can include both binary files and text files, such as SVG, JSON and XML.

The folders are:

- audio: .wav, .aiff - *(audio samples and other sound files)*
- data: .svg, .json, .xml - *(vector graphics, presets, lookup tables, coefficients, etc.)*
- fonts: .ttf, .otf - *(custom fonts used in the application UI)*
- images: .png, .jpg - *(backgrounds, knobs, sliders, VU meters and other UI graphics)*




[link_assets]: https://github.com/KinKout/KinKoutApp-template/tree/main/assets
